# Disclaimer

Markdown Numbering is provided as open-source software for general use.

The extension automatically modifies Markdown heading content when adding or removing heading numbering. Although the project includes automated tests covering supported behavior and edge cases, users are responsible for reviewing generated changes before relying on them.

## Important Considerations

- Keep important documents under version control or make a backup before performing bulk modifications.
- Review changes after using the **Markdown Numbering: Add Heading Numbers** or **Markdown Numbering: Remove Heading Numbers** commands.
- The extension does not guarantee compatibility with every Markdown dialect, syntax extension, or editor-specific Markdown feature.
- Markdown documents may contain syntax or structures that are outside the scope of this project.
- Behavior may change in future versions as the project evolves.
