# Support

Thank you for using File & Folder Generator.

Before requesting support, please make sure you are using the latest version of the extension and review the [README.md](README.md) for documentation, supported features, and usage examples.

## Getting Help

For questions, usage problems, or general support:

- Check the [README.md](README.md) for documentation and examples.
- Search existing [GitHub issues](https://github.com/dxwizco/file-folder-generator/issues) for similar problems.
- If you cannot find an existing issue, open a new issue with enough information to reproduce the problem.
- For general questions or other support requests, use the [DXWIZ Contact page](https://dxwiz.com/contact).

## Reporting a Problem

When reporting a problem, please include:

- The File & Folder Generator version.
- Your VS Code version.
- Your operating system.
- The relevant Markdown definition or a minimal example.
- The expected result.
- The actual result.
- Any relevant error message or additional context.

For reproducible problems, a small File & Folder Generator example is usually more useful than a large document.

Please do not include passwords, access tokens, private documents, personal information, or other sensitive data in issues or support requests.

## Feature Requests

Feature requests are welcome.

Before submitting a feature request, please search existing [GitHub issues](https://github.com/dxwizco/file-folder-generator/issues) to see whether a similar request already exists.

When proposing a feature, please explain:

- What problem it would solve.
- Why the current behavior is insufficient.
- How you expect the feature to work.
- Examples or use cases that demonstrate the proposed behavior.

## Security Issues

Please do not publicly disclose security-sensitive information in a GitHub issue.

For security vulnerabilities or other security concerns, follow the instructions in [SECURITY.md](SECURITY.md).
