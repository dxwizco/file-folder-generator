# Support

Thank you for using Markdown Numbering.

Before requesting support, please make sure you are using the latest version of the extension and review the project's **README.md** for supported behavior and configuration.

## Getting Help

For questions, usage problems, or general support:

- Check the README for documentation and examples.
- Search existing GitHub issues for similar problems.
- If the problem is not already reported, open a new issue with enough information to reproduce it.
- For general questions or other support requests, use the **[DXWIZ Contact page](https://dxwiz.com/contact)**.

## Reporting a Problem

When reporting an issue, please include:

- The Markdown Numbering version.
- Your VS Code version.
- Your operating system.
- The relevant Markdown input.
- The expected result.
- The actual result.
- Any relevant error message or additional context.

For reproducible problems, a small Markdown example is usually more useful than a large document.

Please avoid including passwords, access tokens, private documents, personal information, or other sensitive data in issues or support requests.

## Feature Requests

Feature requests are welcome.

Before requesting a new feature, please check existing issues to see whether a similar request already exists.

When proposing a feature, explain:

- What problem it solves.
- Why the current behavior is insufficient.
- How you expect the feature to work.
- Any examples that demonstrate the proposed behavior.

## Security Issues

Please do not publicly disclose security-sensitive information in a GitHub issue.

For security concerns, follow the instructions in **SECURITY.md**.
