# Code of Conduct

## Our Commitment

The FileForge community is dedicated to providing a welcoming, respectful, and inclusive environment for everyone who contributes, participates, or interacts with the project.

We value constructive collaboration and appreciate contributions from people with different backgrounds, experiences, and perspectives.

---

## Expected Behavior

Community members are expected to:

- Be respectful and professional.
- Communicate clearly and constructively.
- Provide helpful feedback.
- Accept different opinions and approaches.
- Focus on improving the project.
- Help create a positive environment for contributors.

Examples of positive contributions:

- Suggesting improvements.
- Sharing ideas respectfully.
- Providing useful bug reports.
- Helping other users.
- Reviewing pull requests constructively.

---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks.
- Discriminatory language or behavior.
- Trolling or intentionally disruptive behavior.
- Publishing private information without permission.
- Abusive or disrespectful communication.
- Any behavior that discourages others from participating.

---

## Discussions and Reviews

Technical disagreements are normal and encouraged.

When discussing changes:

- Focus on the idea, not the person.
- Explain reasoning behind suggestions.
- Be open to alternative solutions.
- Keep discussions related to improving FileForge.

A different technical opinion does not mean someone is being difficult; healthy discussion helps create better software.

---

## Reporting Issues

If you experience or observe unacceptable behavior:

Please report it by opening a private communication with the project maintainers.

Include:

- A description of the situation.
- Relevant links or examples.
- Any additional context that may help.

All reports will be reviewed appropriately.

---

## Maintainer Responsibilities

Project maintainers are responsible for:

- Maintaining a respectful environment.
- Reviewing contributions fairly.
- Addressing reported issues.
- Helping contributors understand project expectations.

---

## Scope

This Code of Conduct applies to:

- GitHub issues
- Pull requests
- Discussions
- Code reviews
- Any official FileForge community spaces

---

## Thank You

Thank you for helping make FileForge a collaborative and welcoming open-source project.
